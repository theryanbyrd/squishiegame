# Squishy Dumpling Dash 🥟

A kawaii Flappy Bird-style browser game for Evie, Ellie, and Hazel. Bounce your squishy bao through bamboo steamers, collect stars, hearts, and boba pearls, and climb the family leaderboard!

## Features

- **Three player profiles** — Evie 🌸, Ellie 🥟, Hazel ⭐ — no login needed
- **Points & levels** — every run earns points toward 10 levels, from Baby Bao to Kawaii Legend
- **Leaderboards** — Total Points, Best Run, Level, Collectibles, and Daily Champion tabs
- **10 achievements** — from First Flight to Golden Dumpling
- **Unlockable cosmetics** — 6 skins, 5 trails, 5 backgrounds, earned with points
- **localStorage persistence** — all progress saved in the browser, works offline after first load
- Mobile-first, works on iPhone Safari, Chrome, and desktop

## Stack

React + Vite + TypeScript · Phaser 3 for gameplay · Zustand for state · localStorage for persistence

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deploys as a static site (Vercel auto-detects Vite).
